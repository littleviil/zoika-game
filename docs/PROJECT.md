## Обзор проекта

Игрок сбрасывает животных в «стакан». Два одинаковых животных, которые соприкоснулись, сливаются в одно животное следующего уровня. Цель — набрать как можно больше очков до того, как животные выйдут за линию опасности (вверх).

**Цепочка слияний:**
```
Хомяк → Кошка → Свинья → Овца → Слон
```
Два слона при слиянии исчезают, дают бонус +200 очков и эффект ударной волны.

## Как запустить

1. Открыть `white_game/index.html` в браузере (Chrome, Firefox, Safari)
2. Никакой установки или сборки не нужно

> **Внимание:** из-за iframe и загрузки изображений нужен локальный веб-сервер, если браузер блокирует `file://` запросы. Можно использовать `python -m http.server` или расширение Live Server в VS Code.

## Архитектура

Проект разделён на два слоя через `<iframe>`:

```
index.html (меню)
  └─ <iframe src="game/game.html"> (игра)
       ├─ matter.js (физика)
       └─ script.js (игровая логика)
```

**Почему iframe?**
- Изоляция контекста: игра может быть перезапущена простой перезагрузкой iframe
- Независимый экземпляр Matter.js
- Чёткое разделение меню и игры

### Поток данных между слоями

Меню передаёт параметры в игру через URL-параметры:
```
game/game.html?level=easy&t=1234567890
```
- `level` — сложность (easy / medium / hard)
- `t` — timestamp (для обхода кеша при перезапуске)

Игра обновляет UI родительского окна через `window.parent.*`:
```javascript
window.parent.updateScore(score)
window.parent.updateNextAnimal(imgSrc)
```

### `white_game/game/script.js` — Ядро игры

Это самый важный файл. Разбит на секции:

#### Конфигурация (верхняя часть файла)

```javascript
const ANIMALS = [
  { physicsRadius: 24, scoreValue: 10,  path: "hamster.png"  },
  { physicsRadius: 32, scoreValue: 20,  path: "cat.png"      },
  { physicsRadius: 40, scoreValue: 40,  path: "pig.png"      },
  { physicsRadius: 48, scoreValue: 80,  path: "sheep.png"    },
  { physicsRadius: 56, scoreValue: 150, path: "elephant.png" }
]

const GAME = {
  WIDTH: 540,             // Ширина игрового поля (px)
  HEIGHT: 650,            // Высота игрового поля (px)
  DROP_Y: 108,            // Y-позиция сброса животного (под шапкой)
  GAME_OVER_LINE_Y: 324,  // Y-позиция линии опасности
  ...
}

let LEVEL_SCALE = 1.0     // Масштаб животных (меняется по уровню)
const SPRITE_VISUAL = 1.3 // Спрайт на 30% больше физического тела
```

#### Основные функции

| Функция | Что делает |
|---|---|
| `preloadTextures(callback)` | Предзагружает все PNG-спрайты, потом вызывает callback |
| `initPhysics()` | Создаёт движок Matter.js, стены, пол, рендерер |
| `createWallsAndFloor()` | Три невидимых прямоугольника: левая стена, правая стена, пол |
| `createAnimal(x, y, typeIndex, isStatic)` | Создаёт физическое тело + привязывает спрайт |
| `spawnNextAnimal()` | Создаёт животное вверху (статическое, не падает), обновляет превью |
| `dropCurrentAnimal()` | Делает текущее животное динамическим → оно падает |
| `handleCollisions()` | Подписывается на события коллизий Matter.js |
| `handleMerge(bodyA, bodyB)` | Логика слияния двух животных |
| `triggerElephantExplosion(x, y)` | Взрыв слонов: ударная волна + визуальные эффекты |
| `checkGameOver()` | Каждый кадр проверяет, вышло ли животное за линию |
| `setupControls()` | Обработчики клика (сброс) и движения мыши (прицел) |
| `setupOverlayRendering()` | Рисует поверх canvas: линию опасности, прицел, эффекты |
| `startGame()` | Инициализирует всё и запускает игру |
| `restartGame()` | Сбрасывает состояние и перезапускает |

## Игровая механика

### Спавн и сброс животного

1. `spawnNextAnimal()` создаёт животное с `isStatic = true` на высоте `DROP_Y`
2. Животное следует за мышью (только по оси X), не падает
3. При клике вызывается `dropCurrentAnimal()`:
   - Животное переходит в `isStatic = false` → начинает падать
   - `allowGameOverCheck = false` на 900 мс (защита от ложного конца)
   - Через 380 мс спавнится следующее животное

### Слияние

При коллизии двух тел с одинаковым `animalType`:

```
Если это НЕ слоны (type < 4):
  1. Удалить оба тела из физики
  2. Создать новое тело с typeIndex + 1 в среднем положении
  3. Добавить scoreValue нового тела в счёт
  4. Показать вспышку (mergeFlash)
  5. Новое животное помечается justMerged = true на 700 мс

Если это слоны (type == 4):
  1. Удалить оба тела
  2. Добавить +200 очков
  3. Отправить ударную волну всем животным на поле
  4. Показать эффект взрыва (1300 мс)
  5. allowGameOverCheck = false на 2500 мс
```

### Конец игры

Каждый кадр выполняется проверка `checkGameOver()`:

```
Для каждого животного на поле:
  если Y < GAME_OVER_LINE_Y
  И скорость < 3 пикселей/кадр
  И allowGameOverCheck == true
  И НЕ justMerged:
    gameOverFrameCount++

  если gameOverFrameCount >= 10:
    → показать экран game over
```

Таким образом игра заканчивается только если животное стоит выше линии **непрерывно 10+ кадров** (~170 мс).

## Конфигурация и настройки

### Изменить размер игрового поля

В `game/script.js`:
```javascript
const GAME = {
  WIDTH: 540,    // ← ширина canvas
  HEIGHT: 650,   // ← высота canvas
  ...
}
```
> После изменения WIDTH/HEIGHT нужно пересчитать `DROP_Y` и `GAME_OVER_LINE_Y` вручную.

### Изменить позицию линии опасности

```javascript
GAME_OVER_LINE_Y: 324,  // ← Y в пикселях от верха canvas
```
Меньше → опасность ближе к верху → игра легче.
Больше → опасность ниже → игра труднее.

### Изменить очки за животных

В массиве `ANIMALS` в `game/script.js`:
```javascript
{ physicsRadius: 24, scoreValue: 10, path: "hamster.png" },
//                               ↑ изменить это значение
```

### Изменить физические размеры животных

```javascript
{ physicsRadius: 24, ... }
//               ↑ радиус круга в пикселях (на масштабе easy)
```
Пропорции автоматически масштабируются через `LEVEL_SCALE`.

### Изменить задержку спавна следующего животного

```javascript
// в dropCurrentAnimal():
setTimeout(() => spawnNextAnimal(), 380)  // ← миллисекунды
```

### Изменить задержку проверки game over после сброса

```javascript
// в dropCurrentAnimal():
setTimeout(() => { allowGameOverCheck = true }, 900)  // ← миллисекунды
```

### Изменить гравитацию

```javascript
// в initPhysics():
engine.gravity.y = 1.12  // ← 1.0 = стандарт, больше = тяжелее
```

### Изменить физику тел

```javascript
Bodies.circle(x, y, r, {
  restitution: 0.18,    // упругость отскока (0 = нет, 1 = идеальный)
  friction: 0.9,        // трение при столкновении
  frictionStatic: 1.2,  // трение покоя
  frictionAir: 0.015,   // сопротивление воздуха
  density: 0.0008,      // масса тела
  inertia: Infinity,    // Infinity = не вращается
})
```

### Изменить бонус за взрыв слонов

```javascript
// в handleMerge():
GAME.score += 200  // ← бонусные очки
```

### Изменить силу ударной волны от взрыва слонов

```javascript
// в triggerElephantExplosion():
Matter.Body.setVelocity(body, {
  x: (dx / dist) * 50 * falloff,   // ← 50 = сила разлёта по горизонтали
  y: (dy / dist) * 50 * falloff - 20 * falloff  // ← 20 = восходящее смещение
})
```

## Добавление нового животного

Чтобы добавить животное уровня 5 (после слона):

**1. Добавить изображение:**
```
white_game/images/animals/dragon.png  (1250×1250 px, PNG с прозрачностью)
```

**2. Добавить в `game/script.js`:**
```javascript
const ANIMALS = [
  ...
  { physicsRadius: 64, scoreValue: 300, path: "dragon.png" }  // ← новый
]
```

**3. Изменить логику слона** (слон больше не финальный):

В `handleCollisions()` / `handleMerge()` найти проверку:
```javascript
if (typeA === 4 && typeB === 4) {  // было: слон = финальный
```
Изменить на:
```javascript
if (typeA === ANIMALS.length - 1 && typeB === ANIMALS.length - 1) {
```

**4. Обновить туториал в `index.html`** — добавить строку цепочки слияний.

**5. Добавить в таблицу меню в `white_game/script.js`:**
```javascript
const animals = [
  ...
  { name: 'dragon', size: 190, points: 64 }
]
```

## Уровни сложности

| Уровень | `LEVEL_SCALE` | Что меняется |
|---|---|---|
| Лёгкий (easy) | 1.0 | Базовые размеры |
| Средний (medium) | 1.3 | Животные на 30% крупнее |
| Сложный (hard) | 1.6 | Животные на 60% крупнее |

`LEVEL_SCALE` читается из URL-параметра при загрузке `game.html`:
```javascript
const params = new URLSearchParams(window.location.search)
const level = params.get('level') || 'medium'
if (level === 'easy') LEVEL_SCALE = 1.0
else if (level === 'medium') LEVEL_SCALE = 1.3
else if (level === 'hard') LEVEL_SCALE = 1.6
```

Все `physicsRadius` из массива `ANIMALS` умножаются на `LEVEL_SCALE` при создании каждого тела.

### Изменить коэффициенты сложности:

```javascript
if (level === 'easy')   LEVEL_SCALE = 1.0   // ← изменить
if (level === 'medium') LEVEL_SCALE = 1.3   // ← изменить
if (level === 'hard')   LEVEL_SCALE = 1.6   // ← изменить
```

### Добавить новый уровень сложности:

1. Добавить карточку в `index.html` (`#level-screen`)
2. Добавить в `script.js` (меню) обработчик с новым значением
3. Добавить условие в `game/script.js`:
```javascript
else if (level === 'extreme') LEVEL_SCALE = 2.0
```

## Физика

### Движок

Matter.js `Engine` с настройками:
```javascript
positionIterations: 12   // точность расчёта позиций
velocityIterations: 10   // точность расчёта скоростей
constraintIterations: 4  // точность ограничений
```

### Стены и пол

Три статических прямоугольника (не двигаются):
- Левая стена: x = -25, высота = HEIGHT
- Правая стена: x = WIDTH + 25, высота = HEIGHT
- Пол: y = HEIGHT + 25, ширина = WIDTH

### Рендеринг

Matter.js `Render` с `wireframes: false` отображает спрайты.
Дополнительный overlay (линии, эффекты) рисуется на втором `canvas` через `afterRender` событие.

## Визуальные эффекты

### Вспышка обычного слияния (`mergeFlash`)

При слиянии любых животных (кроме слонов):
- Расширяющаяся полупрозрачная окружность
- Длительность: 350 мс
- Цвет: белый с затуханием

### Взрыв слонов (`popEffect`)

Многослойный эффект длительностью 1300 мс:

| Слой | Что рисуется |
|---|---|
| 0–25% | Белая полная вспышка (круг) |
| Основной | Золотое кольцо (расширяется) |
| +небольшая задержка | Оранжевое кольцо (чуть позади) |
| Быстро | Ударная волна — тонкое кольцо с высокой скоростью |
| 12 лучей | Искры (линии от эпицентра) |
| Текст | «+200» — плывёт вверх и растворяется |

### Прицел

Вертикальная пунктирная линия под текущим животным — помогает целиться.

### Линия опасности

Горизонтальная пунктирная красная линия на `GAME_OVER_LINE_Y`.

## Известные особенности кода

### Защита от ложного конца игры

`allowGameOverCheck` — флаг, который временно запрещает проверку game over:

```
После сброса животного       → отключён на 900 мс
После слияния (justMerged)   → отключён на 700 мс для нового животного
После взрыва слонов          → отключён на 2500 мс
```

Без этой защиты животное успевало «зависнуть» в воздухе на доли секунды выше линии и игра заканчивалась случайно.

### Проверка `animalType === 0` (хомяк)

Хомяк имеет `animalType = 0`. В JavaScript `0` — это falsy значение.
Поэтому правильная проверка:
```javascript
// ✅ Правильно:
if (bodyA.animalType === undefined) { ... }

// ❌ Неправильно (сломает хомяка):
if (!bodyA.animalType) { ... }
```

### Инертность (нет вращения)

```javascript
inertia: Infinity
```
Без этого животные вращались бы при столкновениях, и спрайты переворачивались бы вверх ногами.

### Спрайт больше физического тела

`SPRITE_VISUAL = 1.3` — спрайт рисуется на 30% крупнее физического круга.
Это нужно потому что PNG-изображения животных имеют прозрачные края, и при отображении в точный размер физического тела между животными были бы видны зазоры.

### iframe и перезапуск

При нажатии «Играть заново» в конце игры — `restartGame()` сбрасывает всё состояние и вызывает `startGame()` заново внутри того же iframe. При выходе в меню и новом старте — iframe перезагружается полностью (через `src` с новым timestamp).

## Структура для добавления новых фич

### Звук
Добавить Web Audio API в `game/script.js`:
```javascript
const audioCtx = new AudioContext()
// воспроизводить звук слияния в handleMerge()
// воспроизводить звук взрыва в triggerElephantExplosion()
```

### Рекорды
Использовать `localStorage`:
```javascript
// сохранить в restartGame() / game over:
const best = parseInt(localStorage.getItem('bestScore') || '0')
if (GAME.score > best) localStorage.setItem('bestScore', GAME.score)
```

### Пауза
Добавить кнопку и:
```javascript
Matter.Runner.stop(GAME.runner)   // пауза
Matter.Runner.run(GAME.runner, GAME.engine)  // возобновить
```
