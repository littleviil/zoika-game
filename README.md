# ЗУЙКА — Merge Puzzle Game

> Игра в жанре «merge puzzle» (по мотивам Suika Game / 2048)
> Авторы: Е.А. Савельева и М.В. Колесник

---

## Описание

Игрок сбрасывает животных в «стакан». Два одинаковых животного при столкновении сливаются в одно следующего уровня. Цель — набрать как можно больше очков до того, как животные переполнят стакан.

**Цепочка слияний:**
```
Хомяк → Кошка → Свинья → Овца → Слон
```
Два слона при слиянии исчезают, дают бонус +200 очков и эффект ударной волны.

---

## Реализация

Данный репозиторий содержит **браузерный макет** игры (HTML/JS).

Полная версия игры реализована в **3D** на движке **Unreal Engine 4** и распространяется отдельно в виде исполняемого файла (`.exe`).

---

## Как запустить

Открыть `index.html` в браузере — установка и скачивание не требуются.

---

## Уровни сложности

| Уровень | Описание |
|---|---|
| Лёгкий | Маленькие животные, больше места |
| Средний | Стандартный режим |
| Сложный | Крупные животные, меньше места |

---

## Животные

| # | Животное | Очки за слияние |
|---|---|---|
| 1 | Хомяк | 10 |
| 2 | Кошка | 20 |
| 3 | Свинья | 40 |
| 4 | Овца | 80 |
| 5 | Слон | 150 (+200 бонус) |
